FIFO replaces the page that has been in memory the longest.

LRU replaces the page that has not been used for the longest time.

Optimal replaces the page that will not be used for the longest time in the future. It needs to know the future, so it is only a benchmark.

Clock (Second Chance) works like FIFO, but a page whose reference bit is 1 gets a second chance: the bit is cleared and the hand moves on. The small number in each cell is its reference bit.
